## 04 / Human-AI Interaction Principle

When designing for artificial intelligence, interfaces must preserve human agency and explicit authority:

```typescript
type AIAction = {
  context: "visible & verifiable",
  proposal: "previewed before execution",
  execution: "user-confirmed",
  reversible: true
};
```

- **Read vs. Propose vs. Modify:** AI can freely inspect authorized context and generate candidate proposals, but state changes require explicit user confirmation.
- **Reversibility by Default:** Any generative alteration must offer single-action undo and inspection of source provenance.
